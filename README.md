# Alineación Estratégica - Buscador

Aplicación que permite ingresar el objetivo de un proyecto y encontrar los instrumentos, objetivos, metas y conceptos estratégicos más relevantes en la base de datos de políticas internacionales y nacionales.

## Uso
1. Escribe la descripción de tu proyecto.
2. La app devuelve los resultados más similares usando embeddings multilingües.
3. Puedes exportar los resultados a CSV.

## Requisitos
- Python 3.9+
- Ver `requirements.txt`
